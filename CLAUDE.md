# jagiello.ru

Личный сайт-визитка Артёма. Чистый HTML/CSS/JS, без сборки, деплой на GitHub Pages из main.

## Триггерные слова Артёма

Когда Артём пишет одно из этих слов (это не ругательство в контексте, а личные кодовые команды), реагировать сразу, без уточняющих вопросов:

- **pizda** — работаем над сайтом. Считать, что мы уже в папке проекта и готовы к правкам: не спрашивать "какой сайт", сразу спросить что править.
- **jopa** — поднять локальный сервер сайта (`python3 -m http.server` в этой папке) и сразу дать ссылку (обычно http://localhost:8000) для мгновенного просмотра правок в браузере.
